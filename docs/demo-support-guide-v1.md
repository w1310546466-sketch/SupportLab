# 虚构服务 Demo API v1：支持流程

- 文档 ID：`demo-support-guide-v1`
- 服务版本：`demo-api-v1`
- 性质：SupportLab 构造的模拟说明，不代表任何真实供应商。

## 身份与权限

401 表示身份认证相关问题，应核对密钥是否有效、是否正确提供认证信息。403 表示访问权限相关问题，应核对账号权限与目标资源。仅凭状态码不能确定具体原因；当前模拟账号快照没有权限或密钥状态字段，不能完成这两类具体根因诊断。排查时不应要求用户在聊天中提供真实密钥。

## 服务异常与超时

5xx 与超时可能来自服务异常或请求链路问题，应收集请求编号、发生时间、服务版本和对应日志。超时不证明服务端没有执行请求；重试可能重复执行，需先核实服务的重试与幂等规则。当前演示工具不含服务健康数据，证据不足时应整理资料交接。

## 频率与配额

请求太快、短时间调用过多属于频率限制线索；月度次数用完属于月度配额线索。429 不能直接等同于余额不足。确定诊断需要把请求错误码、相同时刻的账号记录和对应版本的文档放在一起核对。

## 资料缺失

未查询、查询后未找到、工具执行失败是不同状态。没有查到账号快照时，不应把用量补成零或沿用以前某次请求的数字。用户偏好只影响展示方式，不改变账号权限、工具预算或证据检查。

## 历史信息

旧会话中的答案可以帮助理解用户指代哪个请求，但不能替代新一轮查询证据。历史配额重置时间只描述当时记录，不能据此承诺当前服务已经恢复。
